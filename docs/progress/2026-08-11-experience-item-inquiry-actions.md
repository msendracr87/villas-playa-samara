# Experience item inquiry actions

## Milestone

The Rentals and Day Tours pages now connect each individual offering directly to its corresponding inquiry form.

- Added an Inquire action to all three rental folios and all nine day-tour chapters.
- Connected each action to the matching option in the page inquiry form.
- Added smooth movement to the form and keyboard focus on the selected option, with reduced-motion behavior respected.
- Kept both form selects editable after an offering has been preselected.
- Added responsive button styling that follows the established Experiences visual language and interaction target sizing.
