# Villas Playa Sámara — Sitemap page direction

> **Purpose:** A public directory of every current website page that is appropriate for visitor navigation.
> **Primary audience:** Guests, travel planners, partners, and visitors looking for a specific resort page.
> **Status:** Implementation direction.
> **Route:** `/sitemap`

## Page goal

Help visitors find any current public page quickly without presenting a dense, unstructured list. The sitemap is organized by the same resort topics used throughout the website.

## Page structure

1. A concise introduction.
2. A section index for quick jumps.
3. A grouped directory that distinguishes overview pages from their detail pages.
4. The standard website footer.

## Publishing exclusions

Do not include:

- Internal presentation and design-system routes.
- The form-success route, which is part of a transactional flow rather than public navigation.
- The 404 state.
- Dining menu routes while their content remains mockup-only.
- Deferred post-launch pages until their content and routes are ready.

## Navigation and metadata

- Add **Sitemap** to the footer navigation.
- Page title: `Sitemap | Villas Playa Sámara`
- Meta description: `Browse every current public page on the Villas Playa Sámara website, organized by resort experience.`

## Maintenance

Update this inventory and the rendered sitemap whenever a public page is added, removed, renamed, or deferred. Accommodation detail links should continue to derive from the canonical accommodation data so their names and route slugs remain synchronized.
